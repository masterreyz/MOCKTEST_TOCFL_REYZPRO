Quick guide

Struktur beta ini dibuat agar Anda bisa menambahkan soal sendiri tanpa mengubah logika aplikasi.

01

Siapkan data JSON

Gunakan struktur pada data/reading.json dan data/listening.json. Setiap soal memiliki id unik, level, topik, prompt, opsi, jawaban, dan penjelasan.

02

Masukkan audio

Simpan file MP3 atau WAV ke folder audio/, lalu isi nilai audio pada soal listening dengan path relatif seperti audio/lesson-01.mp3.

03

Jalankan lewat server

Karena browser membatasi fetch() dari file://, jalankan server lokal: python -m http.server 8000, lalu buka http://localhost:8000.

04

Review pembahasan

Kunci dan pembahasan baru muncul setelah sesi dikirim. Progress tersimpan di localStorage perangkat ini.

Content checklist

Format konten yang konsisten menghasilkan latihan yang lebih berguna.

  • Gunakan satu jawaban benar per soal.
  • Tulis opsi dalam bahasa yang konsisten dengan prompt.
  • Isi pembahasan yang menjelaskan alasan jawaban, bukan hanya “benar/salah”.

Content workspace

Bank soal & audio

Impor JSON yang sudah Anda siapkan, lalu hubungkan rekaman listening. Semua pemrosesan berlangsung di perangkat ini.

01 · SOAL

Impor bank JSON

Satu file untuk Reading dan satu untuk Listening. Impor mengganti bank untuk keterampilan yang sama; file sumber di komputer tidak diubah.

02 · AUDIO

Hubungkan rekaman

Pilih MP3, WAV, M4A, OGG, atau WebM. Nama file harus sama dengan nama pada nilai audio di JSON. Pilihan audio aktif selama tab ini terbuka.
