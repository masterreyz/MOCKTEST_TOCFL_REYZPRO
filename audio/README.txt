FOLDER AUDIO TOCFL STUDIO

Letakkan file audio latihan di folder ini. Contoh nama yang dirujuk oleh data/listening.json:
- l-a1-001.mp3
- l-a1-002.mp3
- l-a2-001.mp3
- l-b1-001.mp3
- l-b1-002.mp3

Anda bebas menggunakan MP3, WAV, M4A, OGG, atau WebM. Jika nama file berbeda, ubah nilai "audio" pada soal listening agar sama, misalnya:
"audio": "audio/lesson-01.mp3"

Contoh audio sengaja tidak disertakan. Sampai Anda memasukkan rekaman, kartu Listening menampilkan status “Audio belum diisi”.
