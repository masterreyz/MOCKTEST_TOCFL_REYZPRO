Quick guide

Mulai dari satu paket, pelajari hasilnya, lalu ulangi soal yang perlu dilatih.

01

Pilih paket atau bagian

Buka Mock Test Band A untuk 50 soal lengkap. Anda juga bisa memilih satu bagian atau mencari satu soal melalui Reading Lab.

02

Masukkan audio

Simpan file MP3 atau WAV ke folder audio/, lalu isi nilai audio pada soal listening dengan path relatif seperti audio/lesson-01.mp3.

03

Buka dan mulai latihan

Ekstrak semua isi ZIP ke satu folder, lalu buka index.html. Data bawaan tersedia untuk penggunaan langsung. Petunjuk mengedit JSON ada di panduan.txt.

04

Periksa hasil Anda

Kunci mengikuti PDF jawaban yang Anda berikan. PDF tersebut tidak memuat pembahasan rinci. Gunakan tombol ulangi soal salah atau kosong untuk berlatih lagi.

Content checklist

Perhatikan jenis soal sebelum menjawab.

  • Bagian 1: pilih gambar sesuai kalimat. Bagian 2: pilih kalimat sesuai gambar.
  • Bagian 3: lengkapi kalimat berdasarkan gambar. Bagian 4: satu opsi hanya boleh digunakan sekali dalam satu paragraf.
  • Bagian 5: baca teks dan pilih jawaban. Nomor 36–40 pada paket 3 dan 4 termasuk bagian 4.

Bank soal & audio

Impor JSON yang sudah Anda siapkan, lalu hubungkan rekaman listening. Semua pemrosesan berlangsung di perangkat ini.

01 · SOAL

Impor bank JSON

Satu file untuk Reading dan satu untuk Listening. Impor mengganti bank untuk keterampilan yang sama; file sumber di komputer tidak diubah.

02 · AUDIO

Hubungkan rekaman

Pilih MP3, WAV, M4A, OGG, atau WebM. Nama file harus sama dengan nama pada nilai audio di JSON. Pilihan audio aktif selama tab ini terbuka.
